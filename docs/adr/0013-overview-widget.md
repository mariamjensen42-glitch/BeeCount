# 桌面小组件：收支速览（Glance + 变更即推 + 深色视觉身份）

收支速览是桌面小组件：小（2×1）展示今日支出与今日收入，中（4×2）四宫格展示今日支出、今日收入、本月支出、本月收入。深色卡片沿用 App 视觉身份。四个核心决策需要记录。

**技术选 Glance（glance-appwidget + glance-material3），不用经典 RemoteViews**：项目是纯 Compose 代码库，Glance 提供声明式 API，与整个项目同一套心智；minSdk 31 原生支持响应式尺寸（targetCellWidth/Height），小/中两档一套代码适配；支持 @Preview 预览与 updatePeriodMillis。经典 RemoteViews 要手写 XML 布局 + 手动管理刷新广播，与项目风格割裂。代价是 Glance 布局能力受限（无 LazyColumn、交互只有点击），但收支速览是纯展示卡片，完全够用。

**刷新：变更即推 + 30 分钟周期兜底，仓库装饰器单点触发**：账目变更（记账确认、删除/撤销、导入、清空、填充演示数据）后主动推一次 widget 更新，receiver 再配 updatePeriodMillis（Android 12+ 最小 30 分钟）兜底。变更即推的实现不在各 ViewModel 手动发广播（入口分散易漏），而是给 EntryRepository 包一层装饰器（WidgetAwareEntryRepository）——所有写操作统一触发，单一接入点。代价是多一层抽象与每次写操作多一次刷新，但写操作本就低频，无感。

**统计口径完全沿用 App 内语义，不发明新口径**：今日 = 日期为今天的账目合计（含补记到今天，与首页今日合计同一套 SQL 口径）；本月 = 当月 1 日至月末的合计（与日历/图表月度一致）；中性记录（退款）一律不计。保证用户在任何界面看到的数字互相咬合。

**深色卡片沿用 App 视觉身份，不跟随系统明暗**：App 本身是暗色独占（ADR 0003、0019），widget 固定深色圆角卡片；「今日/本月」「支出/收入」标签用次级文字色，金额用支出红/收入绿（领域语义色），文本用系统默认字体——Glance 1.1 的 FontFamily 只暴露系统家族名，不支持打包 res/font，等宽字体无法进 widget（圆角由启动器对 widget 自动裁剪）。代价是深色卡片放在浅色壁纸上显得"重"，且 widget 字体与 App 内等宽不一致，但与产品主张一脉相承、字体差异在小组件语境可接受。交互 v1 保持简单：点击任意位置打开 App 首页（日历 tab），不做分区深链——账本/图表页还没有接收外部指定筛选条件的导航参数，硬做要动导航架构。空数据态显示 ¥0.00 不隐藏；选组件预览用一张 4×2 中尺寸静态布局（平台每个 widget 只支持一张预览，小/中各一张不可行，默认添加尺寸为 2×1）。
