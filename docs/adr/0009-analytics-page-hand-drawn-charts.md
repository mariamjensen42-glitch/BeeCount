# 图表页：第四 tab + 手绘图表零依赖

图表分析是继账本页（ADR 0006）、设置页（ADR 0008）之后的第三次范围扩展：新增第四个底部 tab「图表」，按「月度 / 年度」两种粒度聚合展示账目。两个决策需要记录。

**图表不引库，全部手绘**：排行与月内每日柱状用纯 Compose 布局（Row/Box + 按比例宽高 + 动画），年度趋势折线写一小段 Canvas。理由是应用是蜂蜜金深色 + 霞鹜字体的强定制视觉，手绘直接复用语义角色与领域语义色，不需要任何适配层；个人项目数据量小，不需要图表库的复杂手势与动画；零依赖避开版本升级维护。对比过 Vico（Compose 原生，但主题/字体适配仍是活）与 MPAndroidChart（View 体系，与 Compose 割裂）。

**统计口径**：分类排行只排支出（收入类别稀少，排行无意义）；月内每日柱状只画支出、每一天一格（无支出留空位保持趋势感）；颜色用领域语义色支出红，不借蜂蜜金——图表展示的是领域数据而非交互控件。年度高亮为 4 格数字卡：记账笔数、支出最高月、单笔最大支出、日均支出（全年支出 ÷ 有支出的天数，不 ÷365）。

时间选择用左右箭头 + 中间标签，默认定位本月/本年；不在当前周期时标签旁显示「回本月」快捷按钮。v1 不做弹出式月历选择器（个人数据跨度小，箭头可覆盖；跨多年数据时才值得引入）。
