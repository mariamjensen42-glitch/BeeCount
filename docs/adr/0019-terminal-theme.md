# 终端黑客主题（Terminal / Matrix）

2026-08-24 将品牌视觉从「蜂蜜金暖调」迁移为「终端黑客风」，保留暗色独占与领域语义色体系。取代 ADR 0004 的蜂蜜金色板定义与 ADR 0005 的文楷字体选择；领域色独立性（支出/收入不借用 error/primary）沿用 ADR 0004。

## 配色

- 主色：荧光青 `#00E5FF`（终端 cyan / IDE 高亮青），`onPrimary` 深青黑。
- 次级：Matrix 荧光绿 `#00FF41`；三级：电紫 `#C792EA`（IDE 高亮紫）。
- 背景：深黑 `#070B0C`，前景青白 `#E6F5F2`；表面容器为深黑→灰绿的暗色阶梯。
- 主色取青而非纯绿，是为了与领域色的收入绿保持视觉区分；绿色仍作为次级强调与收入绿出现，整体是青绿霓虹的「程序员」观感。

## 字体

- 全文本使用 `FontFamily.Monospace`（系统等宽），数字、符号、拉丁呈控制台/代码观感；中文字形回退系统默认字体，不打包任何字体文件，体积为零。
- 标题与正文只靠 M3 默认字号/字重区分。

## 形状与组件

- `BeeCountShapes` 锐化为 5 级小圆角（4/6/8/12/16dp），呼应硬边终端框。
- `BeeCountDarkColorScheme` 语义角色不变；组件只消费语义角色与领域色，主题换色无需改组件。

## 备注

- 旧字体资源 `res/font/lxgw_wenkai_lite_regular.ttf` 已随本次迁移删除，`app/src/main/res/font` 目录被移除；ADR 0005 所述历史仅供追溯，不再引用。
- 领域语义色保留 `ExpenseRed` / `IncomeGreen` token，仅在校色上对齐新环境。
