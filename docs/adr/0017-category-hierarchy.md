# 类别二级层级与展示属性（子分类 / 图标 / 颜色 / 排序 / 隐藏）

类别从「一级名称快照」升级为支持二级层级与展示元数据的模型。账目**仍存类别名快照**，新增的层级（父→子）、图标 Emoji、颜色、排序与隐藏全部只存在于类别表，账目行不持有这些信息。

## 关键决策

1. **二级层级，账目存完整路径「父·子」快照**：子分类的类别名即完整路径（如「餐饮·外卖」），与账目快照存储天然一致——AI 解析 / 手动选择返回的 `category` 就是 `entry.categoryName` 的原文，展示用 `displayName`（取「·」后段叶子名）。一级分类改名会**级联**更新其子分类的路径前缀与相应账目快照（`remapCategoryNamePrefix`）；子分类改名只更新叶子段（`remapCategoryNameExact`）。路径分隔符为 `·`，用户输入类别名时禁止包含该符号。只做两级，不做更深。

2. **删除 = 归并到目标分类**：删除某分类时用户须选择一个同类型目标分类，该分类及其全部子分类的账目快照统一改写为目标分类名，再删除类别记录。这取代了旧「删除不影响已有账目（历史保留原名）」的语义——因为旧语义下档案里的孤儿类别名既不能新建又无法编辑，是垃圾数据。目标不能是自身。

3. **排序：默认按使用频率，可手动拖拽覆盖**：`sort_order = 0` 表示「跟随使用频率自动排序」（按该类别名快照在 `entries` 中的笔数降序）；拖拽后写入非零 `sort_order`。同一类型内一级分类排前面、其子分类紧随其后；同层级先排手动（`sortOrder > 0` 升序）再排未手动（频率降序，再按 id 兜底稳定）。排序只在类型内生效（支出/收入各自独立）。

4. **图标用 Emoji 字符串**：预置与自定义分类的图标都是 Emoji 文本，存 `icon` 列，无内置矢量图标库依赖；预置分类迁移时补默认 Emoji 与颜色。颜色为 ARGB（`color` 列，默认灰蓝），子分类默认继承父级颜色。

5. **隐藏仅影响候选，不影响历史**：`isHidden` 的分类从 AI 解析 prompt 的候选与确认卡片/编辑弹层的快捷选择中剔除，已入账历史与统计不受影响，微信账单关键词映射仍可使用（映射到一级分类不区分隐藏）。

## 迁移（v6 → v7）

`categories` 表新增五列（`parentId` 可空、`icon`、`color`、`sortOrder`、`isHidden`），均带默认值，无损；老库对预置分类按名称补默认 icon/color。新增列因 SQLite 限制不建外键，父子引用由仓库层保证一致性。

## 影响面

- 领域模型 `Category`、实体 `CategoryEntity`、`CategoryDao`、`RoomCategoryRepository` 与 `ManageCategoryUseCase`。
- 数据库 v6→v7。
- 设置页「管理类别」重构：独立全屏页（替代底部弹层，避免 bottomsheet 滚动抖动），支持新增一级/子分类、改名、图标/颜色选择、隐藏开关、长按拖拽排序、删除归并；列表拖拽用成熟第三方库 `sh.calvin.reorderable`（`LazyColumn` + `ReorderableItem` + `longPressDraggableHandle`），弃用手写 ReorderableColumn。
- 确认卡片 / 编辑弹层的类别快捷 chips：显示图标、用 displayName、过滤隐藏。
